### 👨‍💻 About Me

IT and Cybersecurity professional certified as an **AWS Solutions Architect – Associate (SAA-C03)**, with practical background in cybersecurity operations, systems diagnostics, and IT automation. Currently in the final stages of a Bachelor's degree in **Information Systems (UNISANTA)** and an Associate degree in **Information Security (Anhembi Morumbi)**.

Actively focusing on **Cloud Infrastructure**, **DevSecOps (Shift-Left Security)**, and **Platform Engineering**:
- **Cloud Architecture & IaC:** Designing secure, highly available AWS environments with modular Terraform, zero long-lived credentials, and ephemeral secret management.
- **GitOps & Container Orchestration:** Declarative continuous delivery using Kubernetes (Kind/EKS) and ArgoCD (multi-tenant AppProjects, automated sync, and self-healing).
- **Shift-Left Security & Policy-as-Code:** Enforcing runtime admission control via Kyverno, automated IaC SAST scanning with Checkov, container vulnerability assessment with Aqua Trivy, and dynamic secret injection with the External Secrets Operator (ESO) and AWS IAM OIDC.
- **Observability & Reliability:** Exposing OpenMetrics endpoints with Prometheus, structured JSON logging, and strict separation between liveness and readiness probe lifecycles.
- **Global Communication:** Professional working proficiency in English, experienced in collaborating with cross-functional teams and international stakeholders.

### 🚀 Featured Project

#### 🏛️ [Enterprise GitOps & DevSecOps Cloud Platform](https://github.com/mdhenriques/gitops-lab)
*End-to-end continuous delivery and automated governance platform built according to Enterprise standards and CIS Benchmarks.*

- **Infrastructure & Cloud:** AWS ECR with FinOps lifecycle policies, AWS SSM Parameter Store, and IAM OIDC Federation provisioned with modular Terraform and encrypted S3 state backend.
- **Orchestration & GitOps:** Kubernetes cluster orchestrated via ArgoCD with restricted AppProject boundaries and isolated production namespace.
- **DevSecOps Pipeline:** GitHub Actions workflow featuring zero static credentials, automated Pytest unit testing, Checkov IaC scanning, and Aqua Trivy container CVE checks.
- **Runtime Hardening & Secret Management:** Kyverno Admission Controller enforcing non-root execution (UID 10001) and mandatory resource limits; External Secrets Operator (ESO) syncing SSM parameters and rotating 12-hour ECR tokens.
- **Observability:** Prometheus scraping real-time telemetry and validating decoupled probe execution.
